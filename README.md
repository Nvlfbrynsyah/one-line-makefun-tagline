## What this is

A one-line tagline entry for the make.fun bounty
["One Line, One Week: The make.fun Tagline"](https://make.fun/bounty/u-boge-one-line-one-week-the-make-fun-tagline-66aca584).
The program writes the tagline above to `output/entry.txt`.

## Run

```
node main.ts
```

## Output

The output is deterministic: the same fixed line is written on every run, with no
timestamps, randomness, environment reads, or network access. The grader reads
`output/entry.txt` as `/output/entry.txt`.
